================================================================================
                    KIDS GAME PLATFORM - PROJECT DOCUMENTATION
================================================================================

OVERVIEW
--------
A Hebrew-language educational game platform for children ages 3-5. Built with
React + Vite, featuring mobile-responsive design, RTL layout, and gamification
elements like scoring and progress tracking.

TECH STACK
----------
- React 18 with Vite
- React Router DOM for navigation
- Framer Motion for animations
- CSS Modules with CSS Custom Properties
- LocalStorage for persistence

FEATURES
--------
- 2-step onboarding flow (welcome, name input)
- Letter learning categories organized by groups of 5 letters:
  - אבגדה (א-ה) + quiz
  - וזחטי (ו-י) + quiz (in progress)
  - More categories to be added as letters are created
- Scoring system: 16/8/4/2/1 points based on attempts
- Cute mascot character with mood states
- Mobile-first responsive design
- Audio infrastructure for voice instructions
- Background music with mute/unmute toggle
- Memory card game (classic flip-and-match) with Hebrew letters

    - correct-1.mp3 to correct-4.mp3 - Correct answer phrases
      (כל הכבוד, נהדר, יופי, מצוין) - rate +5%, pitch +3Hz
    - wrong-1.mp3 to wrong-4.mp3 - Wrong answer phrases
      (טעות/לא נכון/אופס/כמעט + נסה שוב) - rate -5%, pitch -2Hz

    - numbers-math: משחקי חשבון (Math games - addition/subtraction)

    LEVEL 3 - Categories (letter groups):
    Hebrew Letters:

      Contains individual nikud games (צֵירֵי, חִירִיק, etc.)
    English:
    - letters-abcd: "ABCD" - Letters A through D
    Numbers - הכרת המספרים:
    - numbers-12345: "12345" - Numbers 1 to 5
    - numbers-67890: "67890" - Numbers 6 to 10
    - numbers-10-20: "10-20" - Numbers 10 to 20
    - numbers-20-100: "20-100" - Numbers 20 to 100

    Arabic:
    - arabic-alef-jim: "أبتثج" - Letters أ through ج
    - arabic-ha-ra: "حخدذر" - Letters ح through ر
    - arabic-zay-dad: "زسشصض" - Letters ز through ض

    ARABIC GAMES GUIDELINES:
    - Instructions: Hebrew text & Hebrew TTS audio (e.g., "מצאו את האות ج")
      Same pattern as English games - instructions in Hebrew, content in Arabic
    - Word labels: Arabic (the letter names and word names stay Arabic)
    - Word audio: Arabic pronunciation (spoken/colloquial dialect عامية)
    - Words: Use everyday colloquial Arabic words kids 3-5 know
      (e.g., بندورة not طماطم for tomato)
    - Images: Reuse existing PNG images when possible
    - Audio files stored in: /public/audio/ar/
    - Letter icons: Green (#2ECC71) background, white letter
    - Instruction TTS voice: he-IL-HilaNeural (edge-tts, Hebrew)
    - Word TTS voice: ar-SA-ZariyahNeural (edge-tts, Arabic)
    - IMPORTANT: ALL word options must have optionAudio - both correct AND
      incorrect answers. This is because users don't know Arabic, so they
      need a speaker icon to preview word pronunciation before choosing.
      The speaker icon renders automatically when optionAudio exists.
      Reuse existing audio files from /public/audio/ar/ when the same word
      appears as a distractor in multiple games (e.g., word-arnab.mp3 for أرنب).

    ENGLISH GAMES GUIDELINES:
    - Instructions: Hebrew text & Hebrew TTS audio (e.g., "מצאו את האות A")
    - Word audio: English pronunciation (e.g., "Apple", "Ant")
    - Images: Reuse existing Hebrew PNG images when possible (word-tapuach for Apple,
      word-nemala for Ant, word-chatul for Cat, etc.) - images are language-neutral
    - Only create new SVG/PNG when no equivalent exists (e.g., word-airplane)
    - Audio files stored in: /public/audio/en/

    Helper functions:

    - getTopicsByLanguage(langId), getCategoriesByTopic(topicId)
    - getTopicForCategory(catId), getLanguageForTopic(topicId) - parent navigation

./src/data/arabicWordBank.js
    Central Arabic word bank for cumulative review questions.
    Maps each of 20 Arabic letters to their words (image, label, audio).
    150 total words sourced from the intro questions of all Arabic letter games.
    Exports:
    - arabicWordBank: Object mapping Arabic letter → array of {image, label, optionAudio}
    - arabicLetterOrder: Array of 20 letters in learning order
    - generateCumulativeReview(letterIndex, prefix, qNum, maxWords):
      Builds an isIntroMultiSelect review question showing words from
      ALL letters learned so far (cumulative across categories).
      Ensures variety by picking 2 words from current letter + rest random.
      Sets showLabels: true so Arabic text appears below each card image.

ARABIC CUMULATIVE REVIEW QUESTIONS:
    Every Arabic letter game now ends with a cumulative review question
    generated by generateCumulativeReview(). It's an intro-style question
    (isIntroMultiSelect: true, all options correct) that shows word objects
    from ALL letters learned up to that point, with Arabic word labels
    displayed below each card image (via showLabels: true flag).
    Audio: /public/audio/ar/review-words-learned.mp3 (Hebrew instruction)
    For letter أ (first): shows all 3 available words
    For letter ب (second): shows 5 words from أ+ب
    For later letters: shows 9 words randomly from all learned letters

LETTER GAMES - LAST QUESTION LOGIC:
    The final question in each letter game should be a MULTI-SELECT asking
    the child to select only the LAST 4 LETTERS learned (not all letters).
    This keeps the game focused and avoids overwhelming children as more
    letters are added. Example: For letter ו, ask for ג,ד,ה,ו (not א-ו).

./src/hooks/useAudio.js
    Audio playback hook with random voice feedback selection:
    - playCorrect() - Play random correct answer voice (4 variations: כל הכבוד, נהדר, יופי, מצוין)
    - playWrong() - Play random wrong answer voice (4 variations: טעות/לא נכון/אופס/כמעט)
    - playComplete() - Play random game completion voice (3 variations)
    - playEncourage() - Play random encouragement voice (3 variations)
    - playSound(type) - Play sound effects (click, star)
    - playInstruction(url) - Play voice instruction audio
    - stopInstruction() - Stop current instruction
    - stopAllAudio() - Stop all audio playback
    - Uses getRandomItem() helper for variety in feedback
    - Handles autoplay errors gracefully

================================================================================
                    HOW TO ACQUIRE IMAGES VIA CHROME DEVTOOLS
================================================================================

OVERVIEW
--------
When adding new word images for games, use Google Images search with Chrome
DevTools MCP to find and download low-resolution cartoon/animated images.
This ensures consistent, child-friendly visuals with small file sizes (~5-15KB).

STEP-BY-STEP PROCESS
--------------------

1. NAVIGATE TO GOOGLE IMAGES
   Use chrome-devtools navigate_page tool:
   - URL: https://www.google.com/search?q=<WORD>+animated&tbm=isch
   - Example: https://www.google.com/search?q=leaf+animated&tbm=isch
   - The "animated" keyword helps find cartoon-style images

2. TAKE A SNAPSHOT TO SEE RESULTS
   Use chrome-devtools take_snapshot tool to get the page structure.
   Look for button elements with image titles (uid like "1_82", "1_86", etc.)

3. CLICK ON A SUITABLE IMAGE
   Use chrome-devtools click tool with the uid of a good cartoon image.
   Look for images from: Vecteezy, Freepik, Clipart Library, PNGTree
   These sites typically have child-friendly cartoon illustrations.

4. FIND THE PREVIEW IMAGE URL
   After clicking, use chrome-devtools evaluate_script to find the largest
   preview image (this is the low-res thumbnail, not the full-size image):

   () => {
     const imgs = document.querySelectorAll('img');
     let largestImg = null;
     let largestArea = 0;
     imgs.forEach(img => {
       const area = img.width * img.height;
       if (area > largestArea && img.src && !img.src.includes('favicon')) {
         largestArea = area;
         largestImg = { src: img.src, width: img.width, height: img.height, alt: img.alt };
       }
     });
     return largestImg;
   }

5. DOWNLOAD THE IMAGE
   Use PowerShell Invoke-WebRequest to download to public/images/:

   powershell -Command "Invoke-WebRequest -Uri '<IMAGE_URL>' -OutFile 'C:\Users\Ori\Desktop\ttd\kids-game\public\images\word-<name>.png'"

6. VERIFY THE DOWNLOAD
   Check file exists and has reasonable size (~5-20KB for low-res):

   powershell -Command "Get-Item 'C:\...\word-<name>.png' | Select-Object Name, Length"

IMAGE NAMING CONVENTION
-----------------------
- Format: word-<english-name>.png
- Examples: word-leaf.png, word-nest.png, word-owl.png
- Use lowercase, hyphenated names
- Keep names simple and descriptive

IMPORTANT NOTES
---------------
- ALWAYS use the Google Images thumbnail preview (encrypted-tbn*.gstatic.com)
  NOT the full-resolution image from the source website
- Thumbnails are typically 200-400px and 5-20KB - perfect for the game
- The preview panel image is already optimized/compressed
- If an image looks wrong (favicon, too small), try another search result

EXAMPLE FULL WORKFLOW
---------------------
For "nest animated":
1. Navigate: https://www.google.com/search?q=nest+animated&tbm=isch
2. Take snapshot, find good cartoon nest image
3. Click on it (e.g., uid="1_82")
4. Run evaluate_script to get largest image src
5. Download: Invoke-WebRequest -Uri 'https://encrypted-tbn0.gstatic.com/...' -OutFile 'word-nest.png'
6. Verify: ~10KB, 300x300px

================================================================================
                    HOW TO ADD A NEW LETTER GAME
================================================================================

CATEGORY STRUCTURE
------------------
Letters are organized into groups of 5 (+ quiz):
- אבגדה (letters-alef-he): א, ב, ג, ד, ה + quiz-alef-he
- וזחטי (letters-vav-yod): ו, ז, ח, ט, י + quiz-vav-yod
- כלמנס (letters-kaf-samech): כ, ל, מ, נ, ס + quiz
- עפצקר (letters-ayin-resh): ע, פ, צ, ק, ר + quiz
- שת (letters-shin-tav): ש, ת + final quiz

--------------------------------------------------------------------------------

STEP 1: ASK FOR EXAMPLE WORDS (DO THIS FIRST!)
----------------------------------------------
Before creating a new letter game, ask which 4-5 words to use.
Words should be:
- Simple, common words kids ages 3-5 know
- Easy to visualize with images
- Clearly start with the target letter

Example for letter ח (Chet):
- חתול (cat)
- חלב (milk)
- חמור (donkey)
- חלון (window)
- חגורה (belt)

--------------------------------------------------------------------------------

STEP 2: CREATE THE GAME FILE
----------------------------
Create: src/data/games/learnX.js (X = letter name in English, e.g., learnChet.js)

Use learnZayin.js as template. Structure:

const learnX = {
  id: 'learn-x',
  categoryId: 'letters-xxx-xxx',  // e.g., 'letters-vav-yod'
  name: 'X',                      // Hebrew letter: ח
  description: 'למדו את האות X',
  icon: 'X',
  type: 'selection',

  questions: {
    easy: [
      // Q1: Introduction - show letter + example words (isIntroMultiSelect: true)
      // Q2: Optional - show different writing styles (if letter has variants)
      // Q3: Multi-select - find all instances of letter in 3x3 grid
      // Q4: Find letter among 6 random letters
      // Q5: Which word starts with this letter? (4 word options)
      // Q6: Find letter among different 6 letters
      // Q7: Another "which word starts with..." question
      // Q8: Multi-select - mark LAST 4 LETTERS learned (e.g., for ט: ו,ז,ח,ט)
    ],
  },
};

IMPORTANT: The final question (Q8) should ask to select the LAST 4 LETTERS
learned (not all letters from א). This keeps the game focused.

--------------------------------------------------------------------------------

STEP 3: GENERATE AUDIO FILES
----------------------------
Required audio files per letter (use edge-tts):

pip install edge-tts  # if not installed

1. Introduction audio:
   edge-tts --voice "he-IL-HilaNeural" --text "זוהי האות X. המילים הבאות מתחילות באות X" --write-media "public/audio/intro-X.mp3"

2. Select all audio:
   edge-tts --voice "he-IL-HilaNeural" --text "בחרו את כל האותיות X" --write-media "public/audio/select-all-X.mp3"

3. Find letter audio:
   edge-tts --voice "he-IL-HilaNeural" --text "מצאו את האות X" --write-media "public/audio/find-X.mp3"

4. Word starts with audio:
   edge-tts --voice "he-IL-HilaNeural" --text "איזו מילה מתחילה באות X?" --write-media "public/audio/word-starts-X.mp3"

5. Mark all (last 4 letters) audio:
   edge-tts --voice "he-IL-HilaNeural" --text "סמנו את כל האותיות Y, Z, W, X" --write-media "public/audio/mark-all-Y-to-X.mp3"

6. Word audio for each example word:
   edge-tts --voice "he-IL-HilaNeural" --text "WORD" --write-media "public/audio/word-WORD.mp3"

IMPORTANT - ALWAYS USE NIKUD FOR TTS:
When generating ANY Hebrew audio with edge-tts, ALWAYS add nikud (vowel marks)
to the text. Without nikud, Hebrew words may be mispronounced by the TTS engine.

Examples of common words that MUST have nikud:
- כֹּל (kol, meaning "all") - without nikud sounds like "kal"
- כֹּל הַכָּבוֹד (kol hakavod)
- בַּחֲרוּ אֶת כֹּל הָאוֹתִיּוֹת (bacharu et kol ha'otiyot)

Letter names with nikud:
- אָלֶף (alef)
- בֵּית (bet)
- גִּימֶל (gimel)
- דָּלֶת (dalet)
- הֵא (he)
- וָו (vav)
- זַיִן (zayin)
- חֵית (chet)
- טֵית (tet)
- יוֹד (yod)
- כַּף (kaf)
- לָמֶד (lamed)
- מֵם (mem)
- נוּן (nun)
- סָמֶך (samech)
- עַיִן (ayin)
- פֵּא (peh)
- צַדִּי (tsade)
- קוֹף (kof)
- רֵישׁ (resh)
- שִׁין (shin)
- תָּו (tav)

TIP: Use an online nikud tool or ask AI to add nikud to Hebrew text before
generating audio files.

--------------------------------------------------------------------------------

STEP 4: REGISTER THE GAME
-------------------------
1. Add import in src/data/games/index.js:
   import learnX from './learnX';

2. Add to games registry object:
   'learn-x': learnX,

3. Add game ID to category in src/data/categories.js:
   games: ['learn-vav', 'learn-zayin', 'learn-chet', ...]

--------------------------------------------------------------------------------

STEP 5: REQUEST IMAGES (DO THIS LAST!)
--------------------------------------
After the game is built and working, request images for the example words.
Images go in: public/images/

Image requirements:
- Simple, clear illustrations (child-friendly style)
- Transparent or white background
- ~200x200 px recommended
- Filename format: word-WORDNAME.png (e.g., word-chatul.png)

Example request format:
"Need images for letter ח game:
- word-chatul.png (cat/חתול)
- word-chalav.png (milk/חלב)
- word-chamor.png (donkey/חמור)
- word-chalon.png (window/חלון)
- word-chagora.png (belt/חגורה)"

--------------------------------------------------------------------------------

STEP 6: CREATE QUIZ WHEN CATEGORY COMPLETE
------------------------------------------
When all 5 letters of a category are done, create a quiz game.
Use quizAlefHe.js as template.

Quiz structure:
- 15 questions (3 per letter)
- 3 question types per letter:
  1. Find letter X among 9 letters (3x3 grid)
  2. What letter does word start with? (shows word image, 9 letter options)
  3. Which word starts with letter X? (4 word options)

Quiz naming: quiz-X-Y.js (e.g., quiz-vav-yod.js)
